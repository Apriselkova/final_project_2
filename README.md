# Файлы для итогового задания

Данный сервис разработан для управления задачами и составления списков дел. 

В директории `tests` находятся тесты для проверки API.

Директория `pkg/web` содержит файлы фронтенда.

В директории `pkg/db` находятся файлы по работе с базой данных.

В директории `pkg/api` находятся файлы обработчиков.

Задания повышенной трудности не выполнялись.

Адрес в браузере http://localhost:7540/

В tests/settings.go указываются сдедующие параметры:

package tests

var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = false
var Search = false
var Token = ``
